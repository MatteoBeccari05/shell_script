## 📌 Info

Benvenuto/a! Questa repository raccoglie vari script **Shell/Bash** creati per automatizzare task quotidiani, gestire il sistema e velocizzare il flusso di lavoro nel terminale Unix.

---

## 🚀 Come Utilizzare gli Script

1. **Clona la repository:**
   ```bash
   git clone https://github.com/MatteoBeccari05/shell_script.git
   cd shell_script
   ```

2. **Rendi gli script eseguibili:**
   ```bash
   chmod +x *.sh
   ```

3. **Esegui lo script che ti interessa:**
   ```bash
   ./nome_script.sh
   ```

---

## ⚙️ Requisiti

- Ambiente Unix-like (**Linux**, **macOS**, o **WSL** su Windows)
- **Bash** o **Zsh**
- Eventuali dipendenze specifiche sono indicate nei commenti all'interno dei singoli script.
